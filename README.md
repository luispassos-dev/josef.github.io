# José Faus — personal portfolio

A responsive, single-page website in **plain HTML, CSS, and JavaScript**, using **Tailwind CSS via CDN**. No framework, package installation, or build step.

Open `index.html` directly in a browser, or serve the folder:

```sh
python3 -m http.server 4173
```

Then visit http://localhost:4173.

The code editor has accessible tabs and a working Run button. The playground includes an interactive color preview. Navigation adapts to mobile, all controls support a keyboard, and animations respect reduced-motion preferences.

## Content

The factual background comes from [José's public LinkedIn profile](https://www.linkedin.com/in/jose-faus): software development, Viana do Castelo, Colab4Food, and IPVC (2021–2024). No unverified projects, technical skills, employment dates, contact details, or testimonials are included. The playground showcases this website itself.

Edit the text, styles, and script in `index.html`. LinkedIn is the contact destination. Add an email address, real project links, or a résumé when supplied.

Tailwind and the Google Fonts need an internet connection. The custom stylesheet also includes the core layout so the content stays readable if the CDN is unavailable.
